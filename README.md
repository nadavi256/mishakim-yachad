# משחקים יחד

גרסת הדגמה (v1) של אפליקציית ספורט חברתית בעברית, מימין לשמאל. הנתונים מקומיים בלבד — אין שרת, אין סופאבייס ואין תשלום.

תצוגה חיה: https://nadavi256.github.io/mishakim-yachad/

## מה כלול

- בית, גילוי, הפעילויות שלי, פרופיל, פרטי פעילות, ופרסום בשלושה שלבים
- פרסום פעילות מוסיף אותה לנתוני הדמה (הפעילויות שלי והפרופיל)
- בפרופיל מופיעות רק פעילויות שהמשתמש הנוכחי (לירון) פרסם
- צ'אט נפתח רק למארגן ולמשתתפים שאושרו
- אין מספרי טלפון ואין כתובות בית של משתמשים אחרים
- מניפסט PWA, וקובץ `capacitor.config.ts` לעטיפה עתידית בלי בניית אפליקציה נייטיב

## הרצה מקומית

```bash
npm install
npm test
npm run dev
```

הכתובת המקומית היא `http://localhost:5173/mishakim-yachad/#/`.

## מבנה הנתונים

`src/data` מגדיר את אותן ישויות שסופאבייס יחזיק אחר כך (פרופיל, פעילות, השתתפות, הודעות). `createRepository()` מחזיר מאגר בזיכרון. מעבר לסופאבייס יהיה דרך `VITE_DATA_BACKEND=supabase` אחרי שיהיה פרויקט — הקובץ `supabaseRepository.ts` עדיין לא מתחבר לרשת.
